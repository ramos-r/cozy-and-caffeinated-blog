# public/images

This folder is for Rebecca's own photography and any cover/gallery images
uploaded through `/admin` that end up served from this repo rather than
Vercel Blob (e.g. a hand-picked hero image committed directly to the repo).

It is **not** a place for placeholder or stock images, or for any of the
Pinterest/mood-board reference screenshots used while designing this site —
see `CLAUDE.md` (in the parent planning folder) → "Images" for why. Until
real photos are added here or uploaded via the admin, pages render the
`CoverImage` component's built-in gradient+icon placeholder instead.
